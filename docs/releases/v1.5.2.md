Analysis Areas 1.5.2 fixes the Analytics request against PostGIS.

The affected spatial snapshot query used the invalid function name
`ST_Box3D(geometry)`. It now calls the documented `Box3D(geometry)` constructor
before extracting the minimum and maximum coordinates with `ST_XMin`, `ST_YMin`,
`ST_XMax`, and `ST_YMax`.

A regression test stores an Analysis Area geometry in a real PostGIS database and
executes the productive Analytics HTTP path through the module router. The test
verifies that PostGIS accepts the bounding-box query, the endpoint does not return
HTTP 500, and the response contains plausible area, polygon, and OSM POI analytics.

This patch contains no migrations and requires no data reset. It is compatible with
the existing Analysis Areas database state used by v1.5.1.

v1.5.2 is required for the final external-module Host cutover tracked in
`oklabflensburg/open-city-planner#197`.
