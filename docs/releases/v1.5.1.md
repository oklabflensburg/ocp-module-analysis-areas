Analysis Areas 1.5.1 completes backend and frontend parity with the former built-in
module while running as a separately installable module on the built-in-free Open
City Planner host.

Highlights:

- complete backend/frontend parity, including runtime routes, map contributions,
  statistics views, SSR and public contracts;
- OSM-based Analysis Areas synchronization through the public snapshot and event
  ports;
- Wikidata enrichment, scheduled refresh and public maintenance service;
- Statistics service dependency supplied by the separately installed Statistics
  module;
- exclusive use of complete public Host SDK ports instead of private Host imports;
- passive discovery of the four adopted Analysis Areas migrations, including while
  the module is disabled;
- compatibility with the built-in-free Host pinned by the release contract;
- verified install-disabled, enable, disable and re-enable lifecycle.

This release does not rebaseline the database, alter published migration IDs, or
require a data export. Existing Analysis Areas tables and migration history are
adopted in place.

`v1.5.0` was reserved by an earlier source tag but was not published as a GitHub or
registry release. The verified release artifact is therefore published as `v1.5.1`.
